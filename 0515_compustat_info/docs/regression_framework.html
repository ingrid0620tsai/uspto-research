你有 71 家公司，這些欄位超過一半都是空白。代表只有特定產業（例如銀行、保險、公用事業）才有這些數字，其他公司根本沒有。放進回歸後：樣本數會從 71 家大幅縮減，而且結果不代表整體樣本。

代表性欄位舉例：銀行業的存款相關欄位（drc 遞延收入、drlt 長期遞延）、保險業準備金、金融機構特有的 fin* 系列欄位（finaco, findlc, findlt...）、衍生性金融商品欄位（derac, derlc）等。這些 219 個欄位低於 80% 非空，你只需要把他們全部排除。
C 類 金額原始欄位 ── 需要轉換後才能用 ~220 個，80%+ 有值但是金額 ▶

這是你的「原材料」。這些欄位資料完整、有變異，但是「百萬美元」單位的金額——你不能直接放進回歸，因為公司規模差距太大。解法是兩種：

① 除以總資產（at）→ 變成比率，讓大公司和小公司可以比較
② 取對數 log(x)→ 壓縮極端值，適用於規模類指標

你總共跑幾個 model？答案：3 個。
Model 1（Column 1）：8 個核心 X 變數，不加產業固定效果 → 主結果，保留 67 筆 CAR 樣本
Model 2（Column 2）：同樣 8 個 X 變數，加產業固定效果 → 主結果，保留 67 筆 CAR 樣本

三個 model 放進論文的同一張表。Model 1 和 Model 2 是主要討論結果，設計重點是保留樣本數；Model 3 用來確認加入 MTB 與更多控制變數後方向是否一致。
MODEL 1 — 主要結果 不含產業固定效果

Y = 你算好的 CAR（3-day 或 5-day，選其中一個作為主要結果）

CAR_i = β₀ + β₁ × Size_i + β₂ × ROA_i + β₃ × Leverage_i + β₄ × Cash_i + β₅ × CAPEX_i + β₆ × PPE_i + β₇ × RD_i + β₈ × RD_dummy_i + ε_i
核心 X 變數（8 個） 目前實作結果：N = 67
風險：低。 不放 MTB、SGA、Payout，因此不會因這些缺值額外損失樣本。這是論文的核心依據。
MODEL 2 — 加入產業控制 含產業固定效果（Industry FE）

X 變數完全一樣，只多加一組產業 dummy（用 SIC 前 2 位數字分類）

CAR_i = β₀ + β₁ × Size_i + β₂ × ROA_i + β₃ × Leverage_i + β₄ × Cash_i + β₅ × CAPEX_i + β₆ × PPE_i + β₇ × RD_i + β₈ × RD_dummy_i + Industry_FE + ε_i
核心 X 變數（8 個） 產業固定效果（Industry FE）
風險：中低。 產業 dummy 會用掉額外自由度（有幾個產業就少幾個自由度），若你的 71 家公司產業過度集中（例如全在同一個 SIC），這個 model 可能無法收斂或產業 dummy 完全沒有意義。執行後先確認產業分布是否合理。
MODEL 3 — 穩健性檢查 14 個 X 變數 + 產業固定效果

在 Model 2 的基礎上，加入 MTB 與 5 個補充指標；SGA、Payout 暫不放入，避免樣本數掉太多

CAR_i = β₀ + β₁–β₈ × 【Model 2 的 8 個變數】 + β₉ × MTB + β₁₀ × CFO + β₁₁ × Goodwill + β₁₂ × Intangible + β₁₃ × Current_Ratio + β₁₄ × Log_Emp + Industry_FE + ε_i
核心 X 變數（8 個） 補充 X 變數（6 個） 產業固定效果
風險：中高。 14 個 X 變數 + 產業 dummy，仍然可能出現以下問題：
① 多重共線性——多個財務比率互相高度相關（例如 Leverage 和 Goodwill 都跟 at 有關），係數會變得不穩定、標準誤暴增
② 過度配適（overfitting）——R² 虛高，但模型對新樣本沒有解釋力
③ 部分補充變數缺失值較多，但已移除 Payout 並用 prcc_f × csho 補 MTB；目前實作結果約 N = 59

使用方式：只用來告訴指導教授「主要結果在更多控制變數下仍然成立」，不作為主要論述依據。如果 Model 3 裡 Model 1 的核心變數係數方向和顯著性沒有大幅改變，就算成功。

Model 2 是本研究最適合向老師報告的主模型：它和 Model 1 一樣保留 67 筆樣本，但額外控制 2-digit SIC 產業差異，因此比較能回答「在同產業差異被控制後，公司特徵是否仍和 CAR 有關」。

用小學生也能懂的方式理解 Model 2：
想像我們要比較同學的考試成績，但有些同學在資優班、有些在普通班、有些在體育班。不同班級本來平均分數就可能不一樣，所以如果直接把所有同學混在一起比，可能會把「班級本來不同」誤看成「某個同學自己的特質造成差異」。

在這份研究裡，「班級」就是公司所在的產業。科技業、醫療業、零售業、金融業本來就可能有不同的市場反應，所以 Model 2 先把產業差異扣掉，再看公司自己的財務特徵，像 ROA、CAPEX、RD，是否仍然和 CAR 有關。
概念本研究怎麼做白話解釋
原始產業變數使用 Compustat 的 sic 欄位sic 是公司產業分類代碼，像是公司身上的產業標籤。

Dummy 是什麼把每個產業轉成 0/1 欄位，例如 sic2_36、sic2_48Dummy 就是「是或不是」。如果公司屬於 SIC2=48，sic2_48=1；不是就等於 0。
Base category每次回歸中，樣本數最多的產業當作被省略的基準組；本次 Model 2 的 base 是 36一定要省略一個產業當作比較基準，不然模型會因為資訊重複而算不出來。

A. 統計概念說明

概念在本研究中的意思如何解讀
Y 被解釋變數本研究的 Y 是 CAR_m1_p1 與 CAR_m2_p2CAR 代表事件附近的市場反應；回歸是在解釋哪些公司特徵和 CAR 有關。
X 解釋變數Size、ROA、CAPEX、RD 等公司特徵X 是用來解釋 Y 的因素。多元回歸會同時放多個 X。
係數 coef每個 X 對 CAR 的估計關係正值表示 X 越高，CAR 平均越高；負值表示 X 越高，CAR 平均越低。在多元回歸中，意思是「控制其他變數後」的關係。
標準誤 std_err係數估計的不確定程度標準誤越大，表示係數越不穩。小樣本或共線性高時，標準誤常會變大。
t 值係數相對於標準誤的大小絕對值越大，代表統計訊號越強。熱力圖就是用 t 值呈現訊號強弱。
p_value 與星號判斷結果是否可能只是隨機出現* 表 p<0.10，** 表 p<0.05，*** 表 p<0.01。星號越多，統計證據越強。
R²模型解釋 CAR 變動的比例例如 R²=0.47，表示模型約解釋 47% 的 CAR 變動。但 R² 會因為多加變數而上升。
Adjusted R²修正後的 R²會懲罰過多變數。小樣本中比 R² 更適合用來比較模型是否真的有改善。
產業固定效果 Industry FE用 SIC 前兩碼控制產業差異不同產業本來就不同，加入 FE 是為了先扣掉產業平均差異，再比較公司特徵和 CAR 的關係。
VIF檢查 X 變數彼此是否太像VIF>5 需要注意，VIF>10 通常代表共線性偏高。Model 3 的 VIF 高，所以不作為主模型。
單變數回歸一次只放一個 X適合畫散點圖與趨勢線，但沒有控制其他因素，因此只能作探索性分析。
多元回歸一次放多個 X正式主模型。可以在控制其他公司特徵後，看單一變數與 CAR 的關係。

B-1. Winsorize 極端值處理：怎麼做、為什麼做

什麼是 winsorize？把極端值「壓」到某個分位數的門檻，而不是刪掉。例如 1%-99% winsorize 的意思是：小於第 1 百分位的值都改成第 1 百分位的值，大於第 99 百分位的值都改成第 99 百分位的值。這樣可以保留樣本數，同時避免少數極端值把回歸結果帶偏。

項目本次做法白話解釋
處理範圍1% 到 99% winsorize把最極端的頭尾各 1% 的值壓到門檻值。以 67 筆來說，大約是把最極端的 1 筆壓到第 2 筆的值。
適用變數所有非 dummy 的財務變數：Size、ROA、Leverage、Cash、CAPEX、PPE、RD、MTB、CFO、Goodwill、Intangible、Current_Ratio、Log_Emp、SGA、Payout這些都是連續型數值，需要處理極端值。
不做 winsorizeRD_dummy、sic2_* 產業 dummydummy 只有 0 和 1，沒有極端值問題，也不能 winsorize。
CAR 是否 winsorize不做CAR 是依變數（Y），是你要解釋的目標，不應該事前「壓」過；而且 CAR 本身分布不會像財務比率那樣容易有極端值。
執行時機在計算完指標、準備跑回歸之前先算完 ROA、Leverage 等，再把極端值壓到門檻。
為什麼選 1%-99%？這是實證財務研究中最常見的做法，平衡了「保守處理極端值」和「不過度改變資料分布」。有些論文用 5%-95%，會比較激進；有些用 0.5%-99.5%，會比較保守。你的樣本只有 71 筆，用 1%-99% 是合理選擇。
和刪除極端值的差別：如果改用「刪除極端值」（trimming），你會直接丟掉那些觀察值，樣本數會減少。Winsorize 則是把極端值「拉回來」但不刪除，所以 N 不變。小樣本情況下，保留 N 比較重要。

B-2. 為什麼只有 Model 3 需要檢查共線性（VIF）？

什麼是共線性？當多個 X 變數彼此高度相關時，OLS 回歸無法清楚區分每個 X 對 Y 的獨立影響，結果是係數變得不穩定、標準誤變大、p-value 變高、甚至方向可能反轉。VIF（Variance Inflation Factor）是衡量這個問題的指標：VIF > 5 需要注意，VIF > 10 通常代表共線性偏高。

模型X 變數數量共線性風險是否需要 VIF 檢查原因
Model 18 個核心 X低不需要變數數量少，且設計時刻意選擇「意義不重疊」的指標（例如 ROA 管獲利，Leverage 管負債，Cash 管流動性）。這 8 個變數彼此的相關性較低。
Model 28 個核心 X + 產業 dummy低不需要產業 dummy 是類別標籤，和財務數值本身不會有數學上的共線性問題。只是會吃掉自由度，但不會造成 VIF 爆高。
Model 314 個 X + 產業 dummy高需要補充控制變數（MTB、CFO、Goodwill、Intangible、Log_Emp）很多都跟原本的核心 X 有重疊：
① Log_Emp 和 Size 都在量公司規模，所以高度相關
② CFO 和 ROA 都跟獲利有關
③ Goodwill、Intangible 和 PPE 都是資產組成
④ MTB 和 Size、ROA 都可能相關
變數太多、彼此重疊，VIF 就會飆高。
Model 3 的實際 VIF 結果：
• Log_Emp VIF = 72.03 — 和 Size 高度重疊
• Size VIF = 61.31 — 和 Log_Emp 高度重疊
• Intangible VIF = 37.41 — 和 Goodwill、PPE 重疊
• Goodwill VIF = 25.21 — 和 Intangible 重疊

• CFO VIF = 21.24 — 和 ROA 重疊
這就是為什麼 Model 3 不能作為主要結論依據。
所以結論是：Model 1/2 設計得比較乾淨，X 變數彼此不太重疊，不需要特別跑 VIF 檢查。Model 3 加入太多「意義重疊」的控制變數，所以必須跑 VIF 來確認共線性有多嚴重——結果發現很嚴重，因此 Model 3 只能當補充檢查，不能當主要故事。

B-3. 統計名詞白話解釋：df_resid、full-rank、R² vs Adjusted R²

這一段用最簡單的比喻解釋回歸報表裡常見的統計名詞。不需要會算，只需要知道它在說什麼、什麼時候該擔心。

📐 自由度（Degrees of Freedom）與 df_resid

比喻：想像你有 10 塊積木（樣本數 N = 10），你要用這些積木來「解釋」某件事。每放一個 X 變數進回歸，就像是「花掉」一塊積木去學那個變數的影響。

名詞公式白話意思
N你的樣本數你手上有幾筆資料。本研究 Model 1/2 是 67 筆，Model 3 是 59 筆。
k你放進去的 X 變數數量（含截距項）Model 1 放 8 個 X + 1 個截距 = 9 個參數；Model 2 再加產業 dummy，參數更多。
df_resid
（殘差自由度）		N - k「花掉」k 塊積木後，你還剩幾塊積木可以用來評估誤差。
Model 2 的 df_resid = 67 - 22 = 45；Model 3 的 df_resid = 59 - 23 = 36。
為什麼 df_resid 很重要？
• 如果 df_resid 太小（例如小於 30），你的統計推論會不穩定，p-value 和係數可能不可靠。
• 如果 df_resid 接近 0 或變成負的，模型根本跑不出來——這叫做「自由度不足」。
• 本研究：Model 1 的 df_resid = 58（很夠），Model 2 = 45（夠用），Model 3 = 36（勉強夠，但要小心）。
🧮 Full-rank 檢查是什麼？

比喻：假設你要解一道數學題，有 3 個未知數（X₁、X₂、X₃），但你只有 2 條獨立的方程式——這樣解不出來，因為「資訊不夠」。Full-rank 檢查就是在確認：你的方程式（資料欄位）是不是「獨立的」、「資訊夠不夠」。

情況白話意思程式怎麼處理
欄位完全重複例如你同時放 sic2_36 和「其他所有 sic2 dummy 都是 0」——這兩件事在講同樣的資訊自動丟掉一個（base category），只保留不重複的
欄位高度相關例如 RD_dummy 在 Model 3 的 59 筆樣本中幾乎沒有變化（全是 1 或全是 0）自動排除該欄位，避免矩陣運算壞掉
欄位可以被其他欄位「推算出來」例如 A + B + C = 常數，那麼知道 A 和 B 就能算出 C自動丟掉 C，因為它不提供新資訊
本研究的 full-rank 排除：
• Model 2 排除了 sic2_58：這個產業在目前樣本中和其他欄位組合會造成矩陣問題，所以自動移除。
• Model 3 排除了 RD_dummy：在 59 筆樣本中，這個 dummy 缺乏足夠變異。
這不是資料壞掉，是數學上必要的處理，讓模型可以正常估計。
📊 R² 和 Adjusted R²：到底要看哪一個？

比喻：R² 就像考試分數，Adjusted R² 就像「扣掉作弊分數後的真實成績」。

指標白話意思特性
R²
（R-squared）		模型解釋了多少比例的 Y 變異 • 範圍 0 到 1，越高代表模型「看起來」解釋力越強
• 問題：加越多 X 變數，R² 一定會上升，就算那些變數沒意義也會上升
• 所以 R² 可能是「假高分」——變數多就分數高
Adjusted R²
（調整後 R²）		扣掉「變數數量的膨脹效果」後的解釋力 • 會懲罰「放太多沒用的變數」
• 如果加的變數沒有真的幫助解釋 Y，Adjusted R² 會下降
• 所以 Adjusted R² 是更誠實的指標

G. 可以直接放進報告的方法文字

本研究使用 0515_final_compustat_firm.xlsx 中 prior_fyear_only (2) sheet 的 71 筆公司/事件觀察值。財務控制變數由 Compustat 原始欄位計算而來，包含公司規模、獲利能力、槓桿、現金、資本支出、不動產廠房設備、研發強度與研發揭露 dummy。所有非 dummy 財務變數皆進行 1% 到 99% winsorize，以降低極端值對小樣本 OLS 的影響。Model 1 放入 8 個核心控制變數；Model 2 在 Model 1 基礎上加入 2-digit SIC 產業固定效果，並以樣本中最多的 SIC2=36 作為 base category；Model 3 再加入 MTB、CFO、Goodwill、Intangible、Current_Ratio 與 Log_Emp 作為穩健性檢查。回歸結果以 Model 1/2 為主要解讀依據，Model 3 因樣本降為 59 且 VIF 偏高，僅作補充。

Model 2 到底具體做了什麼？

Model 2 不是換一批財務變數，而是在 Model 1 的基礎上，多加一組「產業標籤」。目的很單純：先把不同產業本來就可能不同的平均市場反應扣掉，再看公司的財務特徵是否仍然有影響。

一句話版：Model 1 是「所有公司混在一起比」；Model 2 是「先把公司分成不同產業，再比較同樣扣掉產業差異後，ROA、CAPEX、RD 這些公司特徵還有沒有影響」。

D. RD 和 RD_dummy 到底是什麼？

RD 是研發支出強度，公式是 xrd / at。意思是：公司每 1 元資產裡，有多少比例花在研發。問題是 Compustat 裡很多公司的 xrd 是空白，不一定代表公司真的沒有研發，也可能只是沒有揭露。所以我們不能只把它當普通缺值刪掉，否則樣本會變少。

情境原始 xrd原始 at處理後 RDRD_dummy白話意思
公司有揭露研發，且金額大於 05010000.0500001這家公司有研發資料，研發支出約占資產 5%。
公司有揭露研發，但金額是 0010000.0000001這家公司有揭露，且研發支出就是 0。
公司沒有揭露研發NaN10000.0000000為了保留樣本，先把研發當 0；但用 dummy 告訴模型「這筆原本是缺值」。
最重要的理解：RD 管「研發支出占資產多少」；RD_dummy 管「原本有沒有真的揭露研發資料」。兩個一起放，是為了不要把「真的研發為 0」和「資料缺失被補 0」混在一起。
